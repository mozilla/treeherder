Compare Failure Summary

Runs the same comparison as misc/compare_failure_summary.py entirely in your browser: for every completed job in a push, it checks whether the classic Failure Summary (bug_suggestions) and the new Summary tab (*_testsummary.jsonl artifact) agree on what failed.

This page is served over HTTPS, so a browser will block requests to http://localhost:8000 (mixed content) unless this page is itself being opened from localhost/file://.

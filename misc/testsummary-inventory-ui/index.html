Runs the same analysis as scripts/testsummary-inventory.mjs entirely in your browser, without downloading anything to disk. For a push, it fetches every public/test_info/summary.jsonl artifact in parallel and builds an inventory of what survives the TestSummaryFormatter — which record actions, fields, and values are not filtered out — and flags anything still present that the formatter's rules say to drop or strip.

This page is served over HTTPS, so a browser will block requests to http://localhost:8000 (mixed content) unless this page is itself being opened from localhost/file://.

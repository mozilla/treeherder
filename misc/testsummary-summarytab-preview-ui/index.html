Renders the job-view Summary tab (ui/job-view/details/tabs/summaryTab/SummaryTab.jsx) for every job in a push that produced a *_testsummary.jsonl artifact, all on one page — useful for scanning a whole push's failures without clicking through jobs one at a time. Failures are matched against Bugzilla bug suggestions the same way the real Summary tab does, but this page is read-only: there are no bug-filing buttons. Styling reuses Treeherder's own classes/colors so each job section looks like the real tab. Each job also shows the Failure Summary tab's view (ui/shared/tabs/failureSummary/FailureSummaryTab.jsx) side by side, so the two failure sources can be compared directly — this page is meant for a large screen.

This page is served over HTTPS, so a browser will block requests to http://localhost:8000 (mixed content) unless this page is itself being opened from localhost/file://.

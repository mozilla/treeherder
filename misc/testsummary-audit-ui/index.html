TestSummary Field Audit

← TestSummary Inventory

Runs the same analysis as scripts/audit-testsummary-fields.mjs entirely in your browser, without downloading anything to disk. For a push, it fetches every *_testsummary.jsonl artifact in parallel and reports which mozlog actions and fields appear in those artifacts but are never consumed by the job-view Summary tab (ui/helpers/testSummary.js → buildTestSummary). Anything flagged is dead weight in the artifact and a candidate for removal from whatever emits _testsummary.jsonl. For every action that isn't consumed, up to 2 example records are shown, pulled from 2 different files when possible.

This page is served over HTTPS, so a browser will block requests to http://localhost:8000 (mixed content) unless this page is itself being opened from localhost/file://.
